# Navigator
### Delivery services across India

Navigator is a city-based service discovery web app that lets you search any Indian city and instantly see all available delivery and cab services, along with real-time estimated delivery/arrival times.

## Features

- Search across **62+ Indian cities**
- View **200+ service listings** across 5 categories
- Filter by: E-Commerce, Quick Commerce, Food Delivery, Courier, Cab Services
- See average delivery/arrival times per service
- 24×7 availability indicator for each service
- Interactive map that zooms to your searched city
- Clean, minimal UI with zero external dependencies (except Leaflet.js for maps)

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- [Leaflet.js](https://leafletjs.com/) — interactive maps
- [OpenStreetMap](https://www.openstreetmap.org/) — map tiles & geocoding via Nominatim API

## Getting Started

Just open `navigator.html` in your browser — no build steps, no installs needed.

Or clone the repo:
```bash
git clone https://github.com/pavitrakhawshi31/Navigator.git
cd Navigator
open navigator.html
```
